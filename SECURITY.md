# Security Policy

## Supported Versions

This repository contains research code and resources for Hungarian Handwritten Text Recognition (HTR) and Optical Character Recognition (OCR).

Security fixes and maintenance are provided for the latest maintained version of the repository.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or a security-related issue in this repository, please report it privately rather than creating a public GitHub issue.

Security issues may include, but are not limited to:

* Exposure of private or sensitive data.
* Accidental inclusion of credentials, API keys, passwords, or access tokens.
* Insecure data-processing or file-handling functionality.
* Vulnerabilities in scripts, applications, or supporting tools included in the repository.
* Issues that could compromise the integrity of the HTR/OCR models, datasets, or training pipeline.
* Malicious code or unexpected behavior introduced into the repository.

Please contact the repository maintainers through the contact information provided in the repository profile.

When reporting an issue, please provide:

* A clear description of the security issue.
* The affected file, component, model, dataset, or functionality.
* Steps required to reproduce the issue, where applicable.
* The potential impact of the issue.
* Relevant logs, screenshots, or proof-of-concept information.
* A proposed mitigation or solution, if available.

## Sensitive Data

Do not submit personal, confidential, or otherwise sensitive information to the repository.

In particular, contributors should not commit:

* Passwords or authentication credentials.
* API keys or access tokens.
* Private SSH keys.
* Personal identification information.
* Confidential documents.
* Private handwritten documents or images without appropriate permission.
* Restricted or copyrighted datasets without authorization.

If sensitive information is accidentally committed, please report it immediately so that the maintainers can assess the exposure and take appropriate action.

## Dataset and Model Security

This project may contain or use handwritten documents, OCR/HTR datasets, trained models, annotations, and other research resources.

Contributors must ensure that any dataset, document image, annotation, or model added to the repository is legally and ethically suitable for distribution.

Where applicable, dataset and model resources should include appropriate licensing, attribution, provenance, and usage restrictions.

## Responsible Disclosure

We encourage responsible disclosure of security issues.

Please do not publicly disclose a vulnerability before the maintainers have had a reasonable opportunity to investigate and address the issue.

We appreciate researchers and contributors who responsibly report security problems and help improve the reliability, integrity, and security of this Hungarian handwritten HTR/OCR project.
